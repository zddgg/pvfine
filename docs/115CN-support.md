# 115CN 加密 PVF 支持

## 输入约定

pvfine 只接收客户端原始、尚未解密的 `Script.pvf`。把同一客户端版本的以下文件放在同一目录，在界面中只选择 `Script.pvf`：

- `Script.pvf`：115CN 原始外层加密归档；
- `sk.dat`：RSA 密封的分页密钥表；
- `DNF.exe`：RSA 私钥与 AES-256 包装密钥来源。

程序按 PVF 所在目录自动发现伴生文件，不要求用户先解密或解包。

## 115CN 密钥链与格式

115CN 延续分页 AES 外层，但密钥材料和归档规模发生变化：

1. `sk.dat` 为 2,944 字节，由 23 个 RSA-1024 PKCS#1 v1.5 密文块组成。
2. pvfine 从 `DNF.exe` 扫描 PKCS#1/PKCS#8 PEM 私钥并逐块解封，得到 2,592 字节。
3. 从 `DNF.exe` 扫描 AES 包装密钥候选，以 AES-256-CBC、全零 IV 解开对齐部分。
4. 解包结果为 81 把、每把 32 字节的分页密钥。
5. `Script.pvf` 每 `0xA00000`（10 MiB）为一页，每页前 `0x2800`（10 KiB）执行 AES-256-CBC。
6. 候选必须通过 `iNfO` 头流解码后的 `nkpi` 魔数、文件表边界和分组数据边界验证。
7. 81 把页密钥的归档识别为 `paged115cn`，客户端版本显示为 `115CN`；30 把密钥仍识别为 `100CN`。

## 读取和显示

当前样本包含 6,259,057 条文件记录和 96,237 个数据分组。打开后使用原有磁盘 SQLite 文件索引，前端通过 `ListChildren` 按需展开目录，通过 `EditorService.GetFile` 按需解压并显示文件，不会先把六百余万个文件写入磁盘。

集成测试验证了根目录枚举以及 `etc/accountcargo.etc` 的文本读取。

## 保存兼容性

归档对象保留解锁后的 81 把页密钥。现有分页保存路径会重新加密每页保护区；未编辑归档执行 `SaveTo` 后与输入的加密 `Script.pvf` 逐字节一致。

## 测试入口

- `internal/pvf/paged115cn_test.go`：真实加密归档识别、记录和分组数量、样本文件读取、无修改保存一致性。
- `services/paged115cn_test.go`：六百余万文件 SQLite 树索引与编辑器读取。
- 客户端目录通过 `PVF_115CN_DIR` 环境变量注入，仓库不硬编码个人路径和密钥。
